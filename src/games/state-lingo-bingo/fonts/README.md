# State Lingo Bingo board font

`barlow-condensed-latin-700-normal.woff2` is **Barlow Condensed Bold**, Latin subset, used only for state names on the State Lingo Bingo board (card squares, the target, and the target pop-up).

- **Licence:** SIL Open Font License 1.1. The full text is in `OFL.txt`, with the copyright line "Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow)".
- **Source:** the npm package `@fontsource/barlow-condensed` 5.2.5 (`files/barlow-condensed-latin-700-normal.woff2`). `OFL.txt` is from https://github.com/google/fonts/blob/main/ofl/barlowcondensed/OFL.txt. Its licence text matches the package's LICENSE; only the copyright line differs.
- **SHA-256:** `8320299532b4b81498d5b3714d49c9d5938883b55f4c2a1efe6f105bf4a942bd`.
- **Bundling:** the file is bundled by Vite with the game. The app never fetches fonts at runtime. The font is unmodified and not renamed, which the OFL allows when it ships with software.
